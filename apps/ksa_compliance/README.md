# KSA Compliance & ZATCA E-Invoicing Suite

A native Frappe / ERPNext application engineered for the **Kingdom of Saudi Arabia (ZATCA / Fatoora)**, providing end-to-end support for both **Phase 1 (Generation)** and **Phase 2 (Integration)**.

## Main Capabilities

1. **ZATCA Phase 1 Generation:** Dynamic Base64 TLV QR codes with 5 mandatory tags.
2. **ZATCA Phase 2 Integration:** Standard UBL 2.1 XML generation with cryptographic SHA-256 digests.
3. **Tamper-Proof Chaining:** Sequential Invoice Counter Values (ICV) and Previous Invoice Hash (PIH) chaining.
4. **B2B Standard & B2C Simplified Invoicing:** Distinct tax categories and compliance handling.
5. **Onboarding & CSID Management:** Certificate signing request (CSR) generator and CSID enrollment.
6. **Multi-Currency & VAT 15% Support:** Automatic tax splitting and GL ledger postings.
7. **Bilingual Support:** Full Arabic and English interfaces and print formats.
